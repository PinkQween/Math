# Security Policy

## Supported Versions

We actively support the following versions of this project:

- **0.1.x alpha**: Supported  
- All versions older than 0.1.x alpha: Unsupported

Please upgrade to the latest supported version to ensure you receive security updates and patches.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by one of the following methods:

- Open a [GitHub Security Advisory](https://github.com/your-repo/your-project/security/advisories)  
- Send an email to **security@example.com**

Please include as much detail as possible to help us address the issue promptly.

## Response Timeline

We acknowledge all security reports within 48 hours. After assessment, we aim to provide a fix or mitigation within 14 days depending on the complexity and severity of the issue.

## Disclosure Policy

We follow responsible disclosure practices. Once a vulnerability is fixed, we will publicly disclose the issue, including details and remediation steps, to help protect the community. We discourage public disclosure before a fix is available to prevent exploitation.
